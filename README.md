# Telegram Video Bot

Railway-ready Telegram bot starter.

## Railway Variable
Set `BOT_TOKEN` in Railway Variables. Never put the real token in GitHub.

## What it does
- `/start` and `/help`
- Receives Telegram videos
- Receives documents
- Shows Telegram file IDs
- Includes `/health` endpoint for Railway

## Run
`pip install -r requirements.txt`
`python bot.py`
